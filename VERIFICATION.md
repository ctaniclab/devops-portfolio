# Проверки версии 1.1.0

В Linux выполнены Release-сборка WPF и переносимых тестов; тесты чтения реальных OST/PST и регрессии запускаются командой из README.
Добавлены проверки конкретных проблем из пользовательского лога: mapped UnauthorizedAccessException для необязательных MAPI-полей,
RTF-to-HTML с кириллицей/жирным начертанием, подготовка BodyFormat перед HTMLBody, завершение без переименования открытого PST.
Проверяется разрешение точного выбранного сообщения по идентификаторам и отказ при отсутствующем ID.
Проверки предпросмотра сохраняют таблицы/цвета/CID-изображения и удаляют активные элементы, внешние картинки и обработчики событий.
SHA256 тестовых исходников после чтения не меняется.

GitHub Actions дополнительно проверяет опубликованный EXE на Windows через --self-check-output и запускает Microsoft Defender.
Итоги и версия сигнатур находятся в defender-report.json и preview-report.json у проверенного релиза.
Отсутствие сканера/сигнатур, обнаружение, изменение/удаление файла или отказ self-check блокируют публикацию.
Это не подтверждение ложного срабатывания на старой версии 1.0.1 и не гарантия отсутствия любой угрозы.

На CI нет настроенного классического Outlook: полноценная автоматизация Outlook против пользовательского OST остаётся непроверенной.
Имеющийся лог использован для диагностики; содержимое пользовательского OST и письма не предоставлены и не публикуются.
Тест MailArchive.WindowsChecks позволяет проверить реальный PST и одиночный экспорт на целевой Windows-машине с Outlook.
