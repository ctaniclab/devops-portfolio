# Проверки 1.3.1

Переносимые проверки на публичных OST/PST покрывают чтение сжатых блоков, кодировки, RTF, недостоверные счётчики папок,
неперезапись исходников, безопасные имена вложений и MSG, выбор точных идентификаторов, сохранение IMAP-папок и исключение пустых веток.
Добавлены проверки содержимого: пустой результат, правильная тема при пустом теле, обрезанный текст, изменённые байты вложения,
потерянные получатели и изображение без текста не проходят проверку. Изменения пробелов/HTML Word допускаются;
пустое тело у действительно пустого исходника не объявляется потерей данных. Совпадение количества элементов недостаточно без ContentVerified.

Приложение, WPF-ресурсы и проект интеграции Outlook компилируются на Linux с Windows targeting.
Windows Actions после упаковки сканирует EXE Defender, затем запускает именно опубликованный EXE для самопроверки:
главное окно с публичным OST, светлая/тёмная темы, вертикальная/горизонтальная прокрутка страниц и перетаскивание ползунка,
отдельное окно чтения с кириллицей/таблицей и отключёнными скриптами, выбор двух сообщений, выбор всех и переход к форматам PST/MSG.
Снимки интерфейса и отчёты прикладываются к релизу. Неудачная проверка блокирует публикацию.

На CI отсутствует настроенный профиль классического Outlook. Реальные создание PST/MSG, их проверка через Outlook и повторный
импорт в почтовый ящик здесь не выполняются. WindowsChecks содержит проверку PST, одиночного экспорта и двух выбранных Unicode MSG;
запускать на тестовом профиле с публичным архивом и новым именем результата. Не использовать рабочий OST.
Самопроверка UI не заменяет проверку конвертации.

Режим совместимости использует программную отрисовку и sRGB. Настоящий HDR-монитор/калибровка отсутствуют,
поэтому аппаратная поддержка HDR не подтверждается; HdrHardwareVerified в отчёте false.
Сканирование Defender не является гарантией отсутствия любой угрозы и не доказывает ложное срабатывание старой версии 1.0.1.
Предоставленные пользователем журналы не включены в репозиторий или релиз.
