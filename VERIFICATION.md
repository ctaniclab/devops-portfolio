# Проверки 1.5.0

Переносимые проверки на публичных OST/PST покрывают чтение сжатых блоков, кодировки, RTF, недостоверные счётчики папок,
неперезапись исходников, безопасные имена вложений и MSG, выбор точных идентификаторов, сохранение IMAP-папок и исключение пустых веток.
Добавлены проверки содержимого: пустой результат, правильная тема при пустом теле, обрезанный текст, изменённые байты вложения,
потерянные получатели и изображение без текста не проходят проверку. Изменения пробелов/HTML Word допускаются;
пустое тело у действительно пустого исходника не объявляется потерей данных. Совпадение количества элементов недостаточно без ContentVerified.

Всего 134 переносимые проверки. Добавлены реальные проверки файловой структуры MSG: входящие/отправленные/удалённые,
вложенные папки, выбор одного письма без пустых папок, совпадения имён/регистра, недопустимые Windows-имена,
сохранность прежнего результата и одинаковое поведение для источников OST и PST. Регрессия `0x80040107` воспроизводится моделью Outlook с разными хранилищами:
три прохода проверяют использование нового EntryID после Move, правильный StoreID и отсутствие Save в черновики аккаунта.
Отрицательные сценарии проверяют другую папку/хранилище, ошибку повторного открытия и недопустимость успешной отметки для пустого PST.
Это модель жизненного цикла COM, а не выполнение Outlook. Контраст всех 11 палитр проверяется также с прозрачными слоями. Проверяются миграция старого «Стекла»,
различие геометрии/типографики бумаги и классики, отдельные сцены новых тем. 9 проверок оценки времени покрывают
запуск Outlook без ложного прогноза, скорость, таймер без продвижения процента, задержку, восстановление и финальную проверку.

Приложение, WPF-ресурсы и проект интеграции Outlook компилируются на Linux с Windows targeting.
Windows Actions после упаковки сканирует EXE Defender, затем запускает именно опубликованный EXE для самопроверки:
главное окно с публичным OST, все 11 тем и сохранение загруженного архива при их переключении, вертикальная/горизонтальная прокрутка страниц и перетаскивание ползунка,
отдельное окно чтения с кириллицей/таблицей и отключёнными скриптами, выбор двух сообщений, выбор всех и переход к форматам PST/MSG.
Для нативных заголовков после смены темы проверяются HRESULT всех вызовов DWM и обратное чтение тёмного/светлого режима
в главном окне, мастере и окне чтения. Цвета caption/text/border поддерживают Set, но не Get: Windows возвращает E_INVALIDARG
при попытке читать их через DwmGetWindowAttribute. Их успешная настройка отражена как NativeCaptionApiAccepted,
не как подтверждение обратным чтением цвета; NativeCaptionColorReadBackAvailable=false. Дополнительно сохраняются снимки
полного нативного окна в классической и космической темах (в отличие от снимков только клиентской области WPF).
Самопроверка WPF проверяет новые шрифты/геометрию, переключение стекла в непрозрачный режим и обратно,
сброс прозрачности при переходе к обычной теме, а также реальный элемент UI процента/ETA с синтетическими данными.
Отчёт Backdrops разделяет запрос материала, принятие API и активный режим; при недоступной прозрачности проверяется резервный режим.
Принятие API само по себе не доказывает визуальное преломление/размытие рабочего стола: сохраняются снимки нативного окна.
Снимки интерфейса и отчёты прикладываются к релизу. Неудачная проверка блокирует публикацию.

На CI отсутствует настроенный профиль классического Outlook. Реальные создание PST/MSG, их проверка через Outlook и повторный
импорт в почтовый ящик здесь не выполняются. WindowsChecks содержит три прохода полного PST, одиночного PST, PST двух выбранных писем и двух Unicode MSG;
дополнительно независимый XstReader проверяет тело известного письма и темы выбранных писем после отключения PST от Outlook;
запускать на тестовом профиле с публичным архивом и новым именем результата. Не использовать рабочий OST.
Самопроверка UI не заменяет проверку конвертации.

Режим совместимости использует программную отрисовку и sRGB. Настоящий HDR-монитор/калибровка отсутствуют,
поэтому аппаратная поддержка HDR не подтверждается; HdrHardwareVerified в отчёте false.
Сканирование Defender не является гарантией отсутствия любой угрозы и не доказывает ложное срабатывание старой версии 1.0.1.
Предоставленные пользователем журналы не включены в репозиторий или релиз.

Проверки дат: UTC FILETIME отправки/получения, отсутствующие даты, отклонение изменённой даты, состояние черновика,
удаление очереди отправки/уведомлений и три полных цикла CFB записи/повторного открытия. Проверяются неизменность текста,
получателей и SHA256 вложений, а также переход через границу mini-stream 4096 байт. Это проверка формата MSG;
настоящий прогон Outlook по-прежнему требует Windows с настроенным Outlook. Лицензия OpenMcdf и соответствующий исходный
код доступны внутри EXE. Самопроверка проверяет ICO с семью размерами и нативный значок в PE-файле.
